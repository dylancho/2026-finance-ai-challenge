# NEXT 랜딩 스토리보드 v2 (docs/landing-storyboard.md)

구조: 고지서 오프닝 → 노트북 무대(일상→보호) → 알림-낙폭 모핑 전환 → 자산관리 다크 → 브릿지 글귀 → 상속·신탁·의료 칼럼 → 숫자 → 사람 → CTA.
토스 참조: 첨부 스크린샷 4장 기준 — [모듈A]=이미지1(좌 헤드라인+아코디언, 우 기울어진 디바이스+떠 있는 카드), [모듈B]=이미지2(중앙 선언문+키워드 칩 공감 문장), [모듈C]=이미지3(3분할 카드+문제→해결 캡션), [모듈D]=이미지4(다크 변주).
공통 원칙: 문구는 docs/writing-style.md(해요체, 사람 말) 를 따른다 / 한 화면 = 한 메시지 / prefers-reduced-motion 시 완성 상태 즉시 표시 / 노트북·카드 속 콘텐츠는 전부 실제 컴포넌트 렌더(스크린샷 금지) / 사실적 노인 얼굴 비주얼 금지.

## S0. 고지서 오프닝 [pin ①, ~350vh]
1) 비트 A(첫 페인트, 밝은 와이드 숏): 실제 비례의 아파트 철문이 화면 중앙에, 도어락 쪽에 50~60대(뒷모습 3/4, 흰머리·가디건·장바구니)가 서서 문틈에 꽂힌 가로형 고지서로 팔을 뻗고 있다. 전부 SVG/DOM 일러스트(사진 없음).
   비트 B(스크롤 0→6): 손이 고지서를 문틈에서 뽑아낸다 — 고지서(DOM)가 틈 선을 따라 빠져나오며 clip 이 풀리고, 손은 고지서 위에 붙어 같이 움직이며 팔은 IK 로 손목을 따라온다.
   비트 C(6→14): 카메라 푸시인 — 고지서가 중앙으로 와 읽을 수 있는 크기가 되고, 문+사람은 살짝 커지며 서리 베일 아래로 사라진다.
2) 고지서는 실제 한전 청구서를 닮은 가로형(청록 머리띠·천공·격자·수납인·바코드) — "전기요금 38,500원 / 납기일 9월 25일". S0 에는 카피를 얹지 않는다 — 문에 꽂힌 고지서 그림 하나로 읽힌다. (근거였던 JAMA 2020 연체 통계는 화면에서 뺐다)
3) 고지서 텍스트 조각("한국전력" "38,500원" "9/25")이 FLIP으로 날아가 아래에서 떠오른 노트북 화면 속 집행 일지 한 줄로 재조립: [08:00] 한국전력 전기요금 38,500원 · 납기 9/25 · §2 자동이체로 냈어요.
4) 노트북(CSS 프레임 목업) 풀스크린 도달

## CH1. 일상관리 — 노트북 무대 [pin ②, ~250vh]
- 진입: 노트북이 우측 58% 영역으로 물러앉고 좌측 카피 칼럼 오픈. 챕터 인디케이터(01 일상) 표시.
- 비트 1 "공과금, 잊어도 돼요" — 화면: 실행 기록에 [10:00 생활비 나눠 보냈어요] 줄 추가로 찍힘 (S0의 08:00 줄이 살아있는 연속감)
- 비트 2 "생활비는 나눠서, 안전하게" — 화면: 지출설계서 §1 3층 계좌 구조도
- 비트 3 "한도는 내가 정한 만큼만" — 화면: §3 한도 조항 카드 (1회 100만 → 1일 200만 자동 파생 표기)
- 캡션 문법(토스): 문제 한 줄 → 해결 한 줄. 예) "납부 버튼을 직접 누르지 않아도 / 정해 둔 대로 앱이 대신 내요"

## CH2. 금융보호 — 같은 무대, 톤 전환 [pin ② 연장, ~150vh]
- 배경 딥네이비로 하강. 인디케이터(02 보호).
- 화면: 실행 기록에 경고색 줄 — [23:47] 처음 보는 계좌 480만원 이체 시도 · 제4조 보류 · 1차 관리자에게 물었어요. 빨간 알림 카드가 노트북 화면 가장자리 밖으로 살짝 떠오름([모듈A]의 떠 있는 카드처럼).
- 좌측 카피: "이상한 순간, 앱이 먼저 멈춰요" / 서브: "금액 기준 7가지, 상황 기준 3가지로 거래를 살펴요 / 어긋나면 멈추고, 12시간 뒤엔 감독자에게 넘겨요".

## TR. 알림 → 낙폭 모핑 [pin ③, ~120vh] ★시그니처 전환
- 스크롤 진행: 빨간 알림 카드가 모니터에서 튕겨나와(FLIP: 중앙 이동+확대) 카드 배경이 다크 캔버스로 번지고, 카드의 빨간 윤곽선이 좌→우로 펴지며 하락 곡선으로 크로스페이드. -25% 라벨 스탬프.
- 동시에 노트북+칼럼 페이드아웃 (노트북 퇴장).
- 카피 한 줄(중앙): "그리고 어느 날, 시장이 무너집니다"
- 구현: 진짜 패스 모핑 대신 shared-element 크로스페이드(알림 카드 scale-up ↔ SVG pathLength 드로잉 겹침 0.3 구간). reduced-motion: 낙폭 차트 완성 화면으로 점프.

## CH3. 자산관리 — 풀블리드 다크 [모듈D, ~250vh]
- TR의 낙폭 차트가 배경으로 깔린 상태에서 카드 3장 순차 등장:
  1) 실제로 해 온 것 카드 — "지난 급락 때, 7일 만에 42%를 파셨어요" (이력 낙폭 반응)
  2) 내가 정한 것 카드 — 위험자산 상한 20% · 금지 자산(파생·레버리지) (I01·I02)
  3) 투자 비중 조정 카드 — 자산 바가 정한 범위 안으로 조정되는 애니메이션 + 선택지 4장 미니 슬라이드, "아무것도 하지 않기"가 첫 번째
- 헤드라인: "원칙은 건강할 때 정해 둬요" / 캡션: "겁이 나서 팔아 버리는 대신 / 내가 정한 원칙이 선택지를 먼저 정리해요"

## BR. 브릿지 글귀 [모듈B, ~100vh]
- 톤 웜그레이로 상승. 중앙 선언문: "지키는 것은 정했습니다. 이제 남기는 것을 정할 차례입니다"
- 공감 문장: "수많은 (신탁)(상속)(의료·요양) 앞에서, 미루던 결정들" — 칩 톡톡 등장. 다음 섹션 카드 상단이 하단에 고개를 내밈([모듈B] 하단처럼).

## CH4. 상속·신탁·의료 칼럼 [모듈A, ~200vh]
- 좌: 헤드라인 "판단이 어려워지는 날의 절차까지" + 아코디언 4항목(활성 항목만 펼침+설명+CTA):
  1) 신탁설계 초안 — 조항으로 남기는 재산 운용
  2) 제4조 시작 조건 — 평소 패턴 점수 61점 이상 그리고 의료 증빙, AI 혼자 시작하는 일 없음
  3) 의료·요양 비용 — 의료비 계좌 따로, 요양 입소 시 증액
  4) 승인 순서 — 1차 관리자 → 12시간 → 2차 감독자
- 우: 기울어진 설계서 문서 목업 + 조항 카드 1장이 밖으로 떠 있음([모듈A] 구도 그대로, 디바이스 대신 문서).
- 모션 최소 — 이 챕터는 느릴수록 신뢰.

## S7. 숫자 [~100vh]
- "내 설계서에는 지금 빈칸이 몇 개일까요" — 조항 N개 / 빈칸 M개 / 약 K년 유지 카운트업 (예시 프로필 수치)

## S8. 사람 [~100vh]
- 실사 1컷(장바구니 든 손 등, 얼굴 없음). 카피: "빼앗는 설계가 아니라, 돌려주는 설계예요" / "생활계좌 안의 자유는 끝까지 내 것이에요"

## S9. 클로징 CTA [~100vh]
- "오늘의 내가, 미래의 나를 지켜요" + 버튼 "지금 시작하기"(게이트 이동). S0 오프닝 톤 재사용, 수미상관.

## 구현 메모
- pin은 3개로 분리: S0 / CH1~CH2(노트북 컨테이너) / TR. CH3 이후는 whileInView 1회 재생 — 성능·모바일 대응 용이.
- 라이브러리: Motion 기본 + pin 3구간만 GSAP ScrollTrigger, Lenis는 랜딩 라우트 한정.
- 배경색 아크: 어스름 → 미색(CH1) → 딥네이비(CH2~CH3) → 웜그레이(BR~CH4) → 밝음(S7~S9). 색 전환은 스크롤 연동 트랜지션.
- 필요 에셋: S0 스틸 1~2장(문틈 고지서/꺼내는 손), S8 실사 1컷. 나머지 전부 코드.
- 장식 모션은 챕터당 1개 원칙 (CH2 알림 부상, TR 모핑, CH3 재정렬).

## 구현 결정 (2026-09-06)
- 라이브러리: gsap(ScrollTrigger·Flip) + @gsap/react + lenis 설치. Motion(framer)은 쓰지 않고 기존 `Reveal`(IntersectionObserver)로 whileInView 1회 재생을 대신한다. Lenis는 랜딩 라우트에서만 켠다.
- 실사 에셋(S0 스틸 2장, S8 1컷)은 우선 CSS/SVG 임시 비주얼로 만든다. 경로는 `public/landing/s0-door.jpg`, `public/landing/s0-hand.jpg`, `public/landing/s8-basket.jpg`로 고정해 두고, 파일이 생기면 코드 수정 없이 교체된다.
- 기존 랜딩 섹션(인터뷰·설계서·시뮬레이션·이력 대조·FraudSection)은 전부 이 구조로 교체한다. 히어로의 카테고리 버튼 4개는 없애고, 챕터별 CTA가 `focus`(core/safe/invest/estate)를 물고 게이트로 간다.
- 헤더는 유지하되 S0 어두운 오프닝 위에서는 투명·밝은 글자로 바뀐다.
- 수치는 앱의 실제 데모 데이터에 맞춘다: 이상거래 룰 개수는 `ALL_FRAUD_RULES` + 맥락 룰 3종의 실제 합, 이력 낙폭 반응은 ledger 데모 수치, I01·I02는 데모 프로필 값.
