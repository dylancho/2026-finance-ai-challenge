# NEXT 문체 가이드

2026-09-07 확정. 화면에 보이는 모든 문구와 AI가 생성하는 문장에 적용한다.
여러 사람이 나눠 쓰더라도 이 문서를 기준으로 맞춘다.

## 1. 기본 말투 — 해요체

- 화면 문구는 **해요체**로 쓴다. "나갑니다" → "나가요", "확인하세요" → "확인해 주세요".
- 예외는 **문서 본문**뿐이다. 신탁·후견·지출 설계서의 조항 본문, 의뢰서 본문, 법령 인용, 고지·면책 문구는
  합니다체를 유지한다. 그 문서를 감싸는 안내 문장(제목, 설명, 버튼, 도움말)은 해요체다.
- 반말, 명령형("하세요" 단독), 이모지, 느낌표 남발은 쓰지 않는다.

## 2. 문장

- 한 문장에 생각 하나. 대체로 20자 안팎, 길어도 40자를 넘기지 않는다.
- 숫자는 사용자의 숫자로 말한다. "정기 지급액" 대신 "매달 1일 190만원".
- 주어는 사람이거나 "앱"이다. "시스템이 판정합니다" → "앱이 먼저 확인해요".
- 번역투를 쓰지 않는다: ~에 대해, ~를 통해, ~에 있어, ~함에 있어서, ~로부터, ~되어지다, ~적인.
- 대시(—), 화살표(→)는 문장 안에 쓰지 않는다. 단계 표시나 버튼 끝의 "→"만 허용한다.
- 영어 라벨(eyebrow)을 쓰지 않는다. "YOUR DESIGN DOCUMENTS", "Event → Judgement", "TODAY'S PROTECTION" 같은
  대문자 영어 소제목은 한국어로 바꾸거나 없앤다. 브랜드명 NEXT, 고유명사, kWh 같은 단위는 예외다.

## 3. 내부 용어를 화면에 쓰지 않는다

설계 문서와 코드에서 쓰는 말은 화면에서 사람 말로 바꾼다. 코드의 식별자·타입 이름은 그대로 두고 표시 문구만 바꾼다.

| 화면에 쓰지 않는 말 | 대신 쓰는 말 |
|---|---|
| 적재, 적재됨, 적재와 복제 | 불러왔어요, 불러온 이력 |
| 복제된 금융 자아, 페르소나 | 지출 요약, 평소 돈 쓰는 방식 |
| 인사이트, 베이스라인 | 이력에서 읽은 것, 평소 기준 |
| 바이오마커 | 평소 패턴과 비교한 점수 |
| 선언 / 관측, 선언된 원칙 / 관측된 성향 | 내가 정한 것 / 실제로 해 온 것 |
| 대조, 대조군, 이력 대조 | 비교, 정한 것과 실제 비교 |
| 판정층, 판정 엔진, 룰 엔진, 규칙 문장 | AI 해설, 규칙으로 계산한 문장 |
| 판정 원장 | 저장한 선택지 |
| 이벤트, 이벤트 → 판정 | 상황, 상황이 바뀌었을 때 |
| 후보, 검토 후보 | 선택지 (버튼: "저장") |
| 트레이드오프 | 얻는 것과 잃는 것 |
| 노출액, 위험 노출 | 보호 밖에 남는 돈, 빠져나갈 수 있는 돈 |
| 소진, 소진 시점 | 다 쓰는 시점, 자산이 바닥나는 때 |
| 게이트, 전환 게이트, 집행 근거 | 시작 조건, 체결한 서류 |
| Phase, 단계 N, 티어 | 시기 (지금 / 신호가 보일 때 / 진단서가 나온 뒤) |
| 트랙, 통합 플로우, 코어, 챕터, 재진입 | 인터뷰, 기본 질문, 영역, 이어서 답하기 |
| 시드 고정 합성 이력, 목업, 프로토타입 | 예시 이력, 예시 데이터 |
| 마이데이터·오픈뱅킹 연동 | 금융 이력 불러오기 |
| 이상거래 룰, 한도 룰, 맥락 룰 | 보호 규칙, 금액 기준, 상황 기준 |
| 리밸런싱, 포트폴리오 | 투자 비중 조정, 투자 자산 |
| 의사능력, 흠결 | 스스로 결정할 수 있는 상태, 결정이 어려운 상태 |
| 발동 조건, 지급개시 사유 | 시작 조건 (문서 본문에서는 원래 용어 유지) |
| LLM, 모델, 프롬프트 | AI |

## 4. 예시

| 전 | 후 |
|---|---|
| 적재됨 · 10년 · 120개월 | 10년치 이력을 불러왔어요 (120개월) |
| 복제된 금융 자아 | 지출 요약 |
| 선언 vs 관측 | 내가 정한 것과 실제로 해 온 것 |
| 검토 후보 3개 | 선택지 3가지 |
| 지금 설계서대로면 약 23년 뒤 소진 | 지금대로면 약 23년 뒤에 바닥나요 |
| 판정 원장에 기록됨 | 저장했어요 |
| 이 답변에 따라 어떤 제도가 가능한지가 달라집니다. | 이 답에 따라 쓸 수 있는 제도가 달라져요. |

## 5. AI 생성 문장

`app/api/ai/*`와 `app/api/fds`의 시스템 프롬프트에도 같은 규칙을 넣는다. 해요체, 짧은 문장, 번역투와 대시 금지,
위 용어표의 왼쪽 단어 금지. 권유·추천 금지 규칙은 그대로 유지한다.
